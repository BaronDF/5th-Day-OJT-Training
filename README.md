# Ruby OJT – Fifth Day

- Overview

This repository contains my Ruby programming exercises and activities for the fifth day of my On-the-Job Training (OJT).

The activities focus on practicing Ruby pattern matching, understanding different programming concepts, and writing automated tests using RSpec.

- Learning Outcomes

Through these activities, I practiced:

Understanding Ruby pattern matching syntax.

Using variables and conditions in pattern matching.

Working with Ruby blocks.

Understanding recursion.

Creating and testing Ruby classes.
